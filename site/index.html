Point. Click. Pull request.

A web console for KubeVirt that edits git, not the cluster. VMs, networks and firewalls, point-and-click. Every config change is a pull request that ArgoCD applies.

The UI stages. The forge gates. ArgoCD applies.

The path of every config change, from a click to the cluster.

  1. Stage

    Edit in the UI. dotvirt writes the manifest, not the cluster.

  2. Propose

    One pull request per project, with the exact diff.

  3. Merge

    Review and approve in your forge, under your rules.

  4. Sync

    ArgoCD applies git. Live state reads back in seconds.

A thin lens that owns nothing.

  • Acts as you

    Every request runs under your own cluster token. Cluster RBAC is the only permission model.

  • Git is the record

    Each change is a commit with an author and a diff. Review it, revert it, audit it.

  • ArgoCD applies

    dotvirt never writes config to the cluster. Merging the pull request does.

One resource installs it.

  1. Install the operator, from OperatorHub on OpenShift or the OLM catalog in the repo.
  2. Create one Dotvirt resource. The operator provisions the console, its RBAC, the ArgoCD wiring and an optional Forgejo.

Needs KubeVirt and ArgoCD. Runs on OpenShift and vanilla Kubernetes.
